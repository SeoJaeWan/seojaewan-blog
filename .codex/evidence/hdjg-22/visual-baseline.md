# HDJG-22 textual visual baseline

This revision-pinned manifest is the visual baseline for `seojaewan/seojaewan-blog` / `HDJG-22`.
It is textual by design: no screenshot, browser assertion, capture runner, dependency, or CI change is
part of this evidence.

## Provenance and reading rules

- Current implementation revision: `f810a22f600ea5b4e3237e5cae8cd8c78f16da92`.
- Inventory dependency commit: `964a49854351a628691e226a12b62a6c140912e8`; its tree is
  `7ff0be6f6441a4e8765fcdd421cd50077783e9b3`.
- Original-reference revision, used only where explicitly labelled:
  `ef82382c01d16b08103d99ca231f67259e72f0ba`.
- Story IDs below were confirmed in the UI and Shell Storybook build indexes. A source-only row is not
  promoted to a rendered assertion.
- Native state and cross-state are separate. Core/component props own semantic states; Shell owns the
  `entering`/`exiting` presentation lifecycle.
- `RM-GAP` means the semantic state is expected to remain intact under reduced motion, but no explicit
  current `prefers-reduced-motion` or `useReducedMotion` binding exists in the inspected UI/Shell source.
  Motion suppression therefore remains an evidence gap. `RM-N/A` means the row is a static state with
  no animation to suppress.
