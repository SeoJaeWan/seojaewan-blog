## 1. 애니메이션 PR (#180~#189, 모두 병합)

| PR | 판단 |
| -- | ---- |
| #180 최소화 | 도착 위치 실행 중 값 변수 이름 `--motion-window-taskbar-offset-x`·`-y`. 복원도 같은 변수를 쓰게 지음 |
| #181 복원 | 최소화와 같은 변수를 출발 위치로 씀 |

| #183·#184 패널 | 견본의 720(패널 높이)을 px 대신 `translate: 0 100%`(요소 자기 높이)로 옮김. 실제 패널 높이가 달라도 화면 밖으로 빠지게 |
| #186·#187 재부팅 화면 | json의 Arc 트랙(회전·트림)은 ProgressRing에 이미 붙은 `motion-progress-ring`과 같아 새로 만들지 않음. 스토리는 1280x720 BootScreen을 `scale-50`으로 줄여 그림 |
| #188·#189 글자 목록 | 목록 페이드를 같은 클래스에 둠. 클래스는 격자·목록을 감싼 요소에 붙이고, 앱이 격자에 `data-jump-list="grid"`, 목록에 `data-jump-list="list"`를 단다. 스토리는 `TileGrid`+`JumpListLetter`와 `ListItem` 자리표시로 구성 |
| 공통 | 피그마 견본과 모션 스토리를 느리게 보기로 나란히 보는 확인(스킬 8단계)은 하지 않음. 시간·이징은 모션 검사로만 확인 |

## 환경(저장소 밖, 컨테이너에서만)

- Playwright가 Chromium 1248을 찾는데 컨테이너에 1243만 있어 `/opt/pw-browsers`에 1248 이름 링크를 만듦. 로컬 모션 검사는 1243으로 돌렸고 CI는 별도로 통과함
- 커밋 훅이 Node 24를 쓰게 `~/.config/husky/init.sh`에 PATH 추가
- 권한 요청을 줄이려고 컨테이너의 `~/.claude/settings.json`에 허용 목록 추가(저장소에는 넣지 않음)
