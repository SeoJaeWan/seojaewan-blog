# 키보드 지도 (그리기 전에 정할 것)

2026-11-26. 피그마는 읽기만 했다. 네 조립(Desktop 6016:8883, Taskbar 6033:9539, Start 6049:10950, Search 6057:12043)의 걸린 상호작용과 세트 설명의 `흐름:` · `Shell의 흐름:` 줄을 읽어 만들었다.

상태의 뜻

- **문서에 있음**: `.codocs`에 그 키가 적혀 있다.
- **코드에만**: 코드에는 있는데 문서에 없다. 브라우저나 Base UI가 기본으로 해 주는 것은 "기본 동작"이라고 덧붙였다.
- **없음**: 문서에도, 내가 읽은 코드에도 없다.
- 글자 입력(이름, 검색어)은 그 자체가 키보드라 표 1에 넣지 않았다.

문서 줄임말: 접근성 = `.codocs/features/common/accessibility.yaml`, 항목 조작 = `common/item-actions.yaml`, 항목과 폴더 = `common/items-and-folders.yaml`, 우클릭 메뉴 = `desktop/context-menu.yaml`, 작업 표시줄 = `taskbar/taskbar.yaml`, Start = `taskbar/start-menu.yaml`, 검색 = `taskbar/search.yaml`, 탐색기 = `window/file-explorer.yaml`.
코드 줄임말: menu-popup = `apps/web/src/shared/components/menu-popup/menu-popup.tsx`, desktop-icons-layer = `apps/web/src/features/desktop/desktop-icons-layer.tsx`, taskbar-apps-layer = `apps/web/src/features/taskbar/components/taskbar-apps-layer/taskbar-apps-layer.tsx`.

## 5. 문서와 코드가 어긋난 곳

- 범주 카드: 문서는 Esc 뒤 포커스를 그 카드로 돌려준다고 하는데, 코드는 카드가 포커스를 받지 않는 요소다(start-category-cards.tsx).
- 우클릭 메뉴를 여는 키: 코드는 어디서나 Shift+F10·메뉴 키로 열리는데, 문서는 점프 목록 항목에만 적는다.
- 이름 바꾸기: 코드는 Esc = 취소, 밖 누르기 = 확정인데, 문서에는 확정·취소를 가르는 줄이 없다.
- 고정 타일의 포커스 모양: 코드에 없다(pinned-tile.tsx). 피그마에는 이번에 더했다.
- 줄·범주 카드의 포커스 모양: 코드에 없다. 피그마에는 이번에 더했다.

## 6. 확인하지 못한 것

- 글자 머리글과 글자 격자의 키 처리 코드를 찾지 못했다(start-jump-list 폴더에서 키 처리가 검색되지 않았다).
- 검색 패널의 ↑↓·Enter를 처리하는 코드 위치는 확인하지 않았다(문서에 있어 문서를 근거로 삼았다).
- Tab의 실제 차례는 화면을 돌려 보지 않았다.
