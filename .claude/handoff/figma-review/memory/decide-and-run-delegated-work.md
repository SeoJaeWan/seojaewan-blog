논의로 방향을 정하고 작업(하위 에이전트 실행 포함)을 맡긴 뒤에는, 작업 중에 생기는 세부 판단(변형 하나의 처리, 기본값, 이름, 충돌 병합 방식 등)을 이미 정한 원칙에 비추어 스스로 정하고 끝까지 진행한다. 결정 내용은 마지막 보고에 적는다. 멈추고 묻는 것은 데이터를 잃거나 되돌릴 수 없는 경우뿐이다.

**Why:** 2026-10-23 디자인 시스템 재구성에서 논의를 다 마친 뒤 작업 중에 닫기 버튼 아이콘 기본값, 문서 충돌 처리 같은 세부 사항을 하나씩 다시 물어서 사용자가 크게 화를 냈다("싹 다 결정 다 하고 진행해").
**How to apply:** 작업 단계에서는 질문 대신 결정+기록. 하위 에이전트 지시에도 "정한 원칙 안에서 스스로 정하고 보고하라, 데이터 손실 위험 때만 멈춘다"를 넣는다. 관련: [[codocs-only-decided-content]]
