자동 판정 항목은 모든 경우를 확실하게 커버할 수 있을 때만 둔다. 일부만 판정되거나 우회 방법(다른 CSS 방식)으로 오판할 여지가 있으면 그 항목은 판정하지 않고 캡처 표(사람 확인)로 넘긴다. "일부만 판정" 같은 절충안을 선택지로 다시 묻지 않는다.

**Why:** 2026-10-23 그림자(이름 불가 → 값으로 대체)와 절대 위치(붙는 변만 판정)를 차례로 물었을 때, 사용자가 "확실하게 모든 걸 커버할 수 없으면 하지 말라고 했잖아, 왜 같은 걸 반복해"라고 했다. 그림자·절대 위치 모두 판정하지 않기로 했다.
**How to apply:** 판정 항목을 정하거나 구현 차이를 보고할 때, 완전히 덮지 못하는 항목은 스스로 "판정하지 않음"으로 정리하고 이유만 알린다. 사용자에게 설명할 때는 짧은 문장과 구체적인 코드 예시 하나로 쉽게 말한다. 관련: [[figma-parity-redesign]]
